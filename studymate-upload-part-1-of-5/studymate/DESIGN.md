# Studymate design direction

- **Surface mode:** Operate — students move between learning tools and complete study tasks.
- **Audience:** School and university learners who need a calm, practical workspace.
- **Visual language:** Warm paper neutrals, forest-green actions, muted teal, and restrained peach accents. The UI should feel like a well-kept study journal rather than a generic AI console.
- **Typography:** System sans-serif stack for dependable rendering without a remote font dependency.
- **Layout:** Persistent desktop navigation, compact topbar, responsive single-column tool layouts on mobile, and task-specific workspace panels.
- **Motion:** Short page transitions and subtle hover elevation. Respect `prefers-reduced-motion`.
- **Accessibility:** Visible focus states, explicit form labels, keyboard-operable controls, and textual status feedback.
- **Theme:** CSS custom properties provide light and dark surfaces; theme choice is stored in local storage.
